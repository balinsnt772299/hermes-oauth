Privacy Policy

Hermes Agent — last updated 29 September 2026

In one line. Hermes Agent is a single-user personal automation tool. It accesses only the Google Account of its owner, keeps that data on the owner's own private server, and never shares, sells or transfers it to anyone.

1. Who this policy covers

Hermes Agent ("the application") is a private automation project operated by a single individual for his own personal use. The application has exactly one user, who is also its owner and the holder of the Google Account it is connected to. There are no other users, customers or accounts.

2. What Google user data the application accesses

With the owner's explicit consent through Google's OAuth 2.0 flow, the application may access:

  • Gmail — reading, searching, labelling, and sending messages in the owner's own mailbox
  • Google Drive — listing, reading, creating, uploading and deleting files in the owner's own Drive
  • Google Calendar — reading and creating events on the owner's own calendars
  • Google Contacts — reading the owner's own contacts (read-only)
  • Google Sheets and Google Docs — reading and writing the owner's own spreadsheets and documents

3. How the data is used

The data is used solely to carry out tasks the owner explicitly asks for — for example summarising his own inbox, drafting a reply, filing a document, or preparing a personal briefing. The application does not profile the owner, does not build advertising audiences, and does not use the data for any purpose other than performing the requested task.

4. Storage and security

All processing and storage happens on the owner's own private server, on hardware he controls. Google user data is not copied to, stored on, or processed by any third-party cloud service. OAuth credentials are stored in a protected file on that server and are not published or shared. Data in transit uses HTTPS/TLS via Google's own APIs.

5. Sharing and disclosure

  • Google user data is never sold, rented, or shared with third parties.
  • It is never transferred to advertisers, data brokers, or information resellers.
  • It is not used to train, fine-tune or improve any machine-learning or AI model, whether the application's own or a third party's.
  • No human other than the owner reads it.
  • Nothing is disclosed to anyone unless the owner explicitly instructs the application to send it.

6. Limited Use disclosure

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

Data is retained only as long as it is useful for the owner's own tasks, and the owner may delete it at any time. Access can be revoked immediately and permanently at myaccount.google.com/permissions, which stops all future access. To request deletion of any data the application holds, contact the address below and it will be removed.

8. Children

The application is not directed at children and has no users under 18.

9. Changes to this policy

Any change will be published on this page with an updated date at the top.

10. Contact
